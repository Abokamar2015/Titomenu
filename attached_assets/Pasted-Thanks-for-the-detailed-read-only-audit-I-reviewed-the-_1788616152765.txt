The existing TITO Menu customer experience must remain untouched.

Do not redesign or modify the existing Menu UI, customer routes, MenuPage, PrintMenuPage, or existing customer-facing components.

& CO GAME NIGHT must use its own isolated UI, routes, components and styling.

The audit correctly identified that Firebase Auth is not currently used.

Do NOT start a general authentication migration or rebuild the existing authentication system as part of this project.

For & CO GAME NIGHT:

* Existing TITO staff/admin authentication should be reused for management/host access.
* Players should use temporary event sessions.
* Captains/players do not need permanent accounts.

Any authentication changes outside Game Night are out of scope unless absolutely required for security.
